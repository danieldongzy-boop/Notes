# 作业 4/5：放大器反馈结论整理

## 1. 电路和核心直觉

研究对象是 charge redistribution track & hold 中 redistribution phase 的反馈系统：

- 输入电容：`CS`
- 反馈电容：`CF`
- 放大器跨导：`Gm`
- 放大器输出电阻：`rout`
- 输出负载电容：`CL`
- 输入寄生电容：`CX`

核心直觉：

- `CF` 把输出电压的一部分反馈到放大器输入端。
- 因为是电容反馈，反馈强弱由电容分压决定。
- 有反馈后，输出端看到的等效电阻明显变小，主极点主要由 `beta Gm` 和等效负载电容决定。

## 2. Feedback factor / return factor

反馈因子：

```text
beta = CF / (CF + CS + CX)
```

含义：

```text
v- = beta * vout
```

也就是输出电压中有多少比例被反馈到放大器输入端。

结论：

- `CF` 越大，反馈越强，`beta` 越大。
- `CS` 或 `CX` 越大，输入端分掉的电荷越多，反馈因子变小。
- 后面所有关于静态误差、速度、输出阻抗、噪声的结论，基本都绕着 `beta` 展开。

## 3. 闭环传递函数的主要结论

在 `gout = 1/rout << Gm` 时，闭环传递函数近似为：

```text
TF(s) = vout / vin
     ~= -(CS / CF) * (1 - s / (Gm / CF))
        / (1 + s / {Gm / [CL + CS + CX + (CS CL / CF)]})
```

更常用的形式是把它拆成 DC gain、zero、pole。

### DC gain

```text
ADC = TF(0) = -CS / CF
```

如果题目给的是 `CS = CF`，则：

```text
ADC = -1
```

负号来自反相反馈结构。

### Zero

```text
z = +Gm / CF
fz = Gm / (2 pi CF)
```

这是一个右半平面零点的写法来源：传函里有 `1 - s/z`。

通常这个 zero 频率比主 pole 高很多，所以做 settling 近似时常常忽略它。

### Pole

利用反馈后的输出等效电阻，可以把主 pole 写成：

```text
p ~= beta Gm / [CL + (1 - beta) CF]
```

时间常数：

```text
tau = 1 / p ~= [CL + (1 - beta) CF] / (beta Gm)
```

定义：

```text
CLtot = CL + (1 - beta) CF
```

则：

```text
tau ~= CLtot / (beta Gm)
```

## 4. Loop gain

作业 4 中推得 loop gain：

```text
L(s) = Gm CF /
       [(CF + CS + CX) gout
        + (CF CL + CF CS + CL CS + CF CX + CL CX) s]
```

低频时：

```text
L(0) ~= beta Gm rout
```

因此直觉上：

```text
loop gain = feedback factor * amplifier gain
          ~= beta * Gm * rout
```

这就是为什么 `beta` 很重要：它不是闭环增益本身，而是决定有多少输出被送回输入端，进而决定 loop gain 有多大。

## 5. 反馈后的输出电阻

设置输入源为 0，观察输出端小信号电阻：

```text
ro = vout / iout
```

因为：

```text
v- = beta vout
```

输出端电流近似为：

```text
iout = vout/rout + beta Gm vout + s (1 - beta) CF vout
```

若 `rout` 很大，`vout/rout` 可忽略：

```text
ro ~= 1 / [beta Gm + s (1 - beta) CF]
```

也可以看成：

```text
ro ~= 1/(beta Gm) || 1/[s (1 - beta) CF]
```

低频下：

```text
rout,F ~= 1 / (beta Gm)
```

这句话很关键：反馈把原本很大的 `rout` 降低到大约 `1/(beta Gm)`。

## 6. 静态 settling error

渐近增益公式给出：

```text
epsilon_s = [TF(s) - TFideal(s)] / TFideal(s)
          = -1 / [1 + L(s)]
          ~= -1 / L(s)
```

低频近似：

```text
epsilon_s ~= -1 / (beta Gm rout)
```

结论：

- 静态误差由 loop gain 决定。
- loop gain 越大，静态误差越小。
- 经验规则：若想 `|epsilon_s| = 1%`，需要 `L ~= 100`。

作业 5 数值例子：

```text
beta ~= 0.45
20 log10(Gm rout) = 60 dB
epsilon_s ~= 0.22%
```

## 7. 动态 settling error：无 slewing

忽略 zero 后，一阶阶跃响应：

```text
vout(t) = -(CS/CF) * (1 - exp(-t/tau)) * vstep
```

动态误差：

```text
epsilon_d = [TF(t) - TFideal] / TFideal
          = -exp(-t/tau)
```

所以需要的 settling 时间：

```text
t = -ln(|epsilon_d|) * tau
```

常用换算：

```text
|epsilon_d| = 1%    -> t ~= 4.6 tau
|epsilon_d| = 0.1%  -> t ~= 6.9 tau
|epsilon_d| = 0.01% -> t ~= 9.2 tau
```

作业 5 小信号例子：

```text
Gm = 2 mS
beta ~= 0.45
CF = 0.1 pF
CL = 0.5 pF
epsilon_d = 0.2%
t ~= 3.8 ns
```

## 8. Slewing 情况

最大输出电流：

```text
Imax = 2 Gm / (Gm/ID)
```

需要的瞬时电流：

```text
i = Gm vid
```

判断规则：

- 若 `Gm vid < Imax`：没有 slewing，用一阶 settling 公式。
- 若 `Gm vid > Imax`：进入 slewing，输出先以固定斜率变化，再进入指数 settling。

slew rate：

```text
SR = Imax / CLtot
```

其中：

```text
CLtot = CL + (1 - beta) CF
tau = CLtot / (beta Gm)
```

slewing 后的关键量：

```text
Delta vsettle = (Imax / CLtot) * tau
Delta vslew = VOUT - Delta vsettle
Delta tslew = Delta vslew / SR
             = (CLtot / Imax) * VOUT - tau
```

进入指数区以后：

```text
epsilon_d = exp[-(t - Delta tslew)/tau] * Delta vsettle / VOUT
```

所以：

```text
t = -tau * ln(epsilon_d * VOUT / Delta vsettle) + Delta tslew
```

重要结论：

- slewing 只影响动态 settling error。
- slewing 不影响静态 settling error。
- 从 slewing 到线性 settling 的连接点处，斜率必须连续。

作业 5 大信号例子：

```text
vid = 800 mV
Imax ~= 0.266 mA
Gm vid = 1.6 mA > Imax
```

所以有 slewing，最后得到：

```text
tau ~= 0.62 ns
Delta tslew ~= 1.045 ns
t ~= 4.29 ns
```

## 9. 噪声分析里用到的反馈结论

作业 5 用反馈结论把 `Gm` cell 的输出噪声模型简化。

反馈后的输出电阻：

```text
rout,F = 1 / (beta Gm)
```

等效负载电容：

```text
CLtot = CL + (1 - beta) CF
```

电流噪声谱密度：

```text
in^2 = nf * 4 k T gamma Gm
```

转换成等效电压噪声谱密度：

```text
vn^2 = rout,F^2 * in^2
     = nf * 4 k T gamma / (beta^2 Gm)
```

直觉：

- `Gm` 越大，等效电压噪声越小。
- `beta` 越大，反馈越强，输出等效电阻越小，等效电压噪声也越小。
- 噪声带宽由输出主 pole 决定。

## 10. 一页速记版

```text
beta = CF / (CF + CS + CX)

ADC = -CS / CF

L(0) ~= beta Gm rout

epsilon_s ~= -1 / L(0)

rout,F ~= 1 / (beta Gm)

CLtot = CL + (1 - beta) CF

p ~= beta Gm / CLtot

tau ~= CLtot / (beta Gm)

epsilon_d = -exp(-t/tau)

t_no_slew = -ln(|epsilon_d|) tau

SR = Imax / CLtot

slewing affects dynamic settling, not static settling

vn^2 = nf * 4 k T gamma / (beta^2 Gm)
```
