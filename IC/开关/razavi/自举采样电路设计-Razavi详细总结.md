## 一、概述与基本工作原理

自举采样器（Bootstrapped Sampler）是模数转换器（ADC）中不可或缺的组成部分。自举动作能够以极小的功耗代价降低失真并提高速度。

### 1.1 基本原理

MOS 采样开关存在两个失真源：
- **导通电阻 $R_{on}$** 随栅源电压 $V_{GS}$ 变化（而 $V_{GS}$ 随模拟输入变化）
- **沟道电荷**（channel charge）随 $V_{GS}$ 变化

**核心思想**：如果在采样阶段保持 $V_{GS}$ 恒定，失真就能被最小化。做法是将栅极"自举"到源极——即栅极电压跟随源极电压同步变化，等效于在栅极和源极之间接了一个电池。

## 二、设计规格

设计目标：**差分自举采样器**，用于 Nyquist-rate ADC 前端。

| 参数 | 规格 |
|---|---|
| 分辨率 | **10 bit** |
| 采样率 $f_{CK}$ | **5 GHz** |
| 时钟周期 $T_{CK}$ | 200 ps（采样/保持各占一半） |
| 工艺 | **28-nm CMOS**（slow-slow corner） |
| 温度 | 75°C |
| 电源电压 $V_{DD}$ | 0.95 V（worst-case） |
| 单端输入摆幅 | 0.25 – 0.75 V |
| 差分 LSB | $\Delta = 1\ \text{V} / 1024 \approx 1\ \text{mV}$ |

### 2.1 SNR 与失真要求

- 理想 SNR：$\text{SNR} = 6.02N + 1.76 = 62\ \text{dB}$（$N = 10$）
- **谐波失真（HD）目标**：远低于 –62 dB，实际目标约 **–65 dB**（worst case，$A=0.5\text{V}$，$f_{in}\approx 2.5\text{GHz}$ 即 Nyquist 频率）

### 2.2 $kT/C$ 噪声约束

采样器-ADC 级联的 SNR：

$$\text{SNR} = \frac{A^2/2}{kT/(2C_1) + \Delta^2/12}$$

令 $kT/C$ 噪声导致 SNR 退化 **1 dB**，解得：

$$C_1 = 445\ \text{fF} \rightarrow \text{取 } \mathbf{0.5\ pF}$$

### 2.3 带宽约束

采样开关 $M_1$ 与 $C_1$ 构成的低通滤波器在 Nyquist 频率处衰减须小于 **0.5 dB**：

$$R_{on1} \leq 44.5\ \Omega$$

在 $V_{GS} \approx V_{DD} = 0.95\text{V}$ 条件下，需要 $W_1 \gtrapprox 10\ \mu\text{m}$（$L_1 = 28\text{nm}$）。

## 三、仿真要点

### 3.1 时钟与输入频率选择

- 若 $f_{CK}$ 是 $f_{in}$ 的整数倍 → 只采样输入波形上的有限几个点，无法揭示真实性能
- **正确做法**：使 $f_{CK}/f_{in}$ 为无理数（或长周期有理数），确保采样点逐渐覆盖整个输入正弦波
- 例：$f_{CK} / f_{in} = 5\ \text{GHz} / 570\ \text{MHz} = 500/57$，每 500 个时钟周期后采样点才重复

> **图 2**：整数倍与无理数倍频比下的采样效果对比

![页面2](page_002.png)

### 3.2 FFT 处理与 Nyquist 区

- ADC 只感知保持电容 $C_1$ 上的保持值 → FFT 时间点必须限定在**保持模式**
- 等效于模拟输入在时域乘以冲激串 → 频域中卷积冲激串
- **第一 Nyquist 区**：$[-f_{CK}/2, +f_{CK}/2]$
- 三次谐波 $3f_{in}$ 若超出 $f_{CK}/2$，会被混叠到 $f_{CK} - 3f_{in}$

## 四、增量式设计流程（五步法）

Razavi 采用**增量式设计**方法，逐步引入非理想因素：

| 步骤 | 内容 |
|---|---|
| **Step 1** | 保留理想电池，仅分析 track-mode 失真 |
| **Step 2** | 加入采样-保持功能（除 $M_1$ 外其余开关为理想） |
| **Step 3** | 将 $M_2$ 和 $M_4$ 替换为 MOS 器件 |
| **Step 4** | 将剩余开关替换为 MOSFET |
| **Step 5** | 将电池替换为电容 $C_B$ |

### 4.1 Step 1：Track-Mode 失真（理想电池）

- $f_{in}=570\text{MHz}$：HD3 = –79 dB，HD5 = –97 dB（性能优异）
- $f_{in}=2.47\text{GHz}$：HD3 = **–56 dB**（恶化严重）

> 原因：体效应导致 $R_{on1}$ 显著变化，输出相位随输入大幅偏移。

- **解决**：将 $W_1$ 从 10μm 加倍到 **20μm** → HD3 改善至 **–66 dB**

> **图 4 & 5**：Track-mode 输出频谱与波形

![页面3](page_003.png)

### 4.2 Step 2：基本采样器（理想开关 $M_2$/$M_4$）

加入理想开关实现采样-保持，$M_2$/$M_4$ 定义 $R_{on}=50\Omega$。

- $f_{in}=570\text{MHz}$：HD3 = **–83 dB**，HD5 = –110 dB
- $f_{in}=2.47\text{GHz}$：HD3 = **–64.4 dB**（比 track-mode 的 –66 dB 略差）

> 额外恶化归因于：虽然 $V_{GS}$ 恒定，但阈值电压随 $V_{in}$ 变化，调制注入到 $C_1$ 的沟道电荷量。

> **图 6**：基本采样器与输出频谱

![页面4](page_004.png)

### 4.3 Step 3：MOS 开关实现 $M_2$/$M_4$

- $M_4$ 必须为 **NMOS**（拉 X 到地）
- $M_2$ 必须为 **PMOS**（拉 X 到高电位）
- **N-well 连接**：$M_2$ 的 N-well 必须接 **节点 P**（而非 X），否则 $M_2$ 关断时 N-well 被拉低导致 PN 结正偏

**初始选择**：$W_2 = W_4 = 2.5\ \mu\text{m}$，时钟上升/下降时间 10ps

- $f_{in}=570\text{MHz}$：HD3 = –68 dB
- $f_{in}=2.47\text{GHz}$：HD3 = **–58 dB**（显著恶化）

> **根本问题**：当 $V_{in} > 0.5\text{V}$ 时 $V_P > 1.5\text{V}$，即使 $M_2$ 栅极拉到 1V，$M_2$ 仍无法关断 → $M_4$ 无法将 X 拉低 → $M_1$ 不完全关断。

### 4.4 解决关断问题：加入 $M_3$ 和 $M_6$

**关键修改**：在保持模式下断开电池与模拟输入的连接。

> **图 7 & 8**：加入 $M_3$/$M_6$ 的电路与输出频谱

![页面4](page_004.png)

- CK 为高时，$V_B$ 产生 $V_P = V_{DD}$，使 $M_2$ 可靠关断
- $M_3$ 栅极也需要**自举到 $V_{in}$**（否则 $R_{on}$ 变化过大）
- 选择 $W_3 = 2.5\ \mu\text{m}$，$W_6 = 1\ \mu\text{m}$

**结果**：HD3 = –84 dB（570MHz）/ **–60 dB**（2.47GHz）

### 4.5 Step 5：电容 $C_B$ 替代电池

将电池替换为电容 $C_B$，加入 $M_5$ 在保持模式为 $C_B$ 充电到 $V_{DD}$。

> **图 9**：电容自举的三种实现方案

![页面5](page_005.png)

**三个关键问题**：

1. **$M_5$ 的栅极驱动**：若直接由 CK 驱动，CK 为高时 $V_P = V_{in} + V_{DD}$ 可达 1.75V → $M_5$ 无法关断 → $M_5$ 栅极也必须自举到 $V_{in}$

2. **$M_5$ 的 N-well**：必须接节点 P

3. **$C_B$ 的最小值**：受两个效应制约
   - **电荷共享**（charge sharing）：$C_B$ 与节点 X 的寄生电容（$M_1$/$M_3$/$M_5$ 栅电容 + $M_2$/$M_4$/$M_5$ 漏极电容）分压 → 自举电压低于 $V_{DD}$
   - **充电时间常数**：$M_5$-$C_B$-$M_6$ 串联的 $\tau$ 必须 < 100ps（$T_{CK}/2$）

**迭代优化过程**：

| 迭代 | $C_B$ | $W_5$ | $W_6$ | $W_4$ | HD3 @ 2.47GHz |
|---|---|---|---|---|---|
| 初始 | 0.25pF | 2.5μm | 2.5μm | 2.5μm | –63 dB |
| 第二次 | 0.5pF | 5μm | 5μm | 2.5μm | –63 dB（收益递减） |
| 最终 | 0.5pF | 5μm | 5μm | **5μm** | **–65 dB** |

> 第二次迭代收益递减的原因：节点 X 的大寄生电容与 $M_4$ 形成大时间常数，减慢 $M_1$ 的关断速度。加大 $W_4$ 到 5μm 解决了此问题。

## 五、器件应力问题（Device Stress）

在 track 模式下，电路中的某些 MOSFET 承受远高于 1V 的 $V_{DS}$ 或 $V_{GS}$，导致长期性能退化。

> **图 10**：器件应力保护方案

![页面6](page_006.png)

### 5.1 保护 $M_4$

- $M_4$ 关断时承受峰值 $V_{DS} = V_{in} + V_{DD} \approx 1.75\text{V}$
- **方案**：串联 cascode 器件 $M_8$，确保 $V_{DS4} \leq V_{DD}$，$M_8$ 承担约 0.5V
- 两个器件均需 $W = 10\ \mu\text{m}$

### 5.2 保护 $M_2$

$M_2$ 承受栅源电压约 1.75V。唯一的方案是让 $M_2$ 栅极也跟随 $V_X$（即 $V_{in}$）变化：

- **Track 模式**：$M_2$ 栅极 → $V_{in}$
- **Hold 模式**：$M_2$ 栅极 → $V_{DD}$

实现方案（图 10b/c）：
- $M_a$：在 hold 模式将 $M_2$ 栅极接 $V_{DD}$
- $M_b$：在 track 模式将 $M_2$ 栅极接 $V_{in}$
- $M_c$：提供低阻通路，栅极自举到 $V_{in}$（当 CK 仅达 $V_{DD}$ 时，$M_a$ 在 $V_{in}$ 接近 0.75V 时无法导通）
- $M_a$ 看似冗余，但对电路正确启动是必需的

### 5.3 最终参数

| 器件 | 宽度 | 说明 |
|---|---|---|
| $M_1$ | **20 μm** | 采样开关 |
| $M_2$ | **2.5 μm** | PMOS 上拉 |
| $M_3$ | **5 μm** | 电池断开开关 |
| $M_4$ | **10 μm** | NMOS 下拉 |
| $M_5$ | **5 μm** | $C_B$ 充电 PMOS |
| $M_6$ | **2.5 μm** | 充电通路 |
| $M_8$ | **10 μm** | $M_4$ 的 cascode 保护 |
| $M_a$ | **0.25 μm** | 启动辅助 |
| $M_b$ | **1 μm** | 栅极切换 |
| $M_c$ | **5 μm** | 低阻系列开关 |
| $L$ | **28 nm** | 所有器件 |
| $C_B$ | **0.5 pF** | 自举电容 |

## 七、输入电流问题

当初为满足 0.5dB 衰减选 $R_{on} \approx 45\Omega$，后来为满足线性度将 $M_1$ 宽度加倍使 $R_{on1} \approx 23\Omega$。

- 在 Nyquist 频率附近，前一采样值与当前输入值差值可达满摆幅（≈0.5V）
- 初始电流峰值：$0.5\text{V} / 23\Omega \approx \mathbf{22\ mA}$
- 该电流必须由前级 buffer 提供
- **对 Buffer 的要求**：输出阻抗必须远低于 $23\Omega$，这是极大的设计挑战

## 八、关键要点总结

| 序号 | 要点 |
|---|---|
| 1 | 自举的核心：保持 $V_{GS}$ 恒定以消除 $R_{on}$ 和沟道电荷调制 |
| 2 | 增量式设计方法：从理想到实际，逐步引入非理想因素并定位问题 |
| 3 | 仿真要使用无理数频比，避免采样点周期性重复 |
| 4 | FFT 只能取保持模式的时间点，且需注意混叠效应 |
| 5 | 体效应是高频下 $R_{on}$ 变化的主因 → 需要足够宽的采样管 |
| 6 | PMOS 上拉管在输入较大时无法关断 → 必须在 hold 模式断开电池 |
| 7 | 电容自举面临电荷共享和充电时间常数两个核心约束 |
| 8 | 28nm 工艺下器件应力是现实问题，需 cascode 和栅极自举来保护 |
| 9 | 极低的 $R_{on}$ 带来巨大的输入电流需求，对前级驱动提出极高要求 |
| 10 | 最终电路在 5GHz/10bit 规格下，以 1mW 功耗实现 –64.3dB HD3 |
