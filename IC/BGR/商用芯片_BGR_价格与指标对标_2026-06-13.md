# 商用芯片 BGR / 电压基准价格与指标对标

## 1. 说明

- 查询日期：2026-06-13。
- 价格均为美元，不含税、运费和中国进口成本；小批量价格会随库存变化。
- `1片价`优先采用 DigiKey 或厂家官方商城；`1k价`优先采用厂家官网。
- “专用基准”指芯片的主要功能就是产生参考电压。
- “集成基准”指 BGR/参考源只是 LDO、DC/DC、ADC、MCU 等芯片内部的一部分。
- 厂家未公开内部拓扑时，只写“内部参考/架构未公开”，不能仅凭产品类别断言一定是传统 Brokaw BGR。

### 价格与性能观察

1. **$0.2–1 区间**：目标不是极低 TC，而是低成本、足够准确和容易使用。典型是 TL431、LM4040、MCP1501。
2. **约 $1.2**：MCP1502 已能提供 7 ppm/°C，说明通过斩波、二阶补偿和量产修调，普通封装 bandgap 可以达到论文级的中高精度。
3. **约 $3–4**：REF2025、REF5025A-Q1 同时提供低漂移、低噪声、输出驱动和宽温区保证。
4. **约 $9–13**：REF70、REF54 的价格主要换取 0.8–2 ppm/°C、低频噪声、长期漂移和更严格的量产筛选，而不仅是初始精度。
5. 商用品价格包含封装、测试、温度筛选、修调、良率、长期稳定性验证和供货保证，不能直接理解为 BGR 电路面积的价格。

## 4. 为什么集成 BGR 的公开指标较差

集成芯片的数据手册通常不会公布内部 BGR 的独立 TC，原因是客户最终使用的是系统功能：

- LDO 保证 `VOUT`，误差还包括误差放大器、反馈电阻、负载调整和 dropout。
- Buck 保证输出电压，误差还包括比较器、反馈网络、纹波和控制环路。
- ADC 保证 gain error、offset、INL 和总未调整误差，参考源漂移包含在 gain drift 中。
- MCU 常只保证参考电压的宽松范围，通过校准换取更低面积、功耗和成本。

因此，不能把 TLV700 的 ±2% 直接说成“内部 BGR 是 ±2%”，只能说整个稳压器的最终输出保证为 ±2%。

## 5. 商用产品对论文设计的启示

### 低成本目标

可参考 MCP1501/LM4040：

- 初始精度约 0.1%。
- TC 约 50–100 ppm/°C。
- 简单、一点修调或较少测试时间。
- 商用价格约 $0.5–1。

这与多数低功耗论文的 25–75 ppm/°C 比较接近，是现实的第一版流片目标。

### 中高精度目标

可参考 MCP1502/REF2025：

- 初始精度 0.05–0.1%。
- TC 7–8 ppm/°C。
- 往往采用斩波、二阶补偿和量产修调。
- 商用价格约 $1.2–4。

若希望设计具有明显产品价值，`<10 ppm/°C + <0.1%初始误差 + 宽温实测` 是很好的目标组合。

### 高端精密目标

可参考 ADR4525/REF70/REF54：

- 初始精度约 0.02–0.025%。
- TC 0.8–2 ppm/°C。
- 低频噪声和长期漂移与 TC 同样重要。
- 单片价格约 $9–13，批量约 $3–8。

这类产品通常需要复杂补偿、offset cancellation、精密修调、封装应力控制及严格筛选，仅靠典型角仿真无法对标。
