type: user
---

偏好循序渐进、结合实际电路与工程背景的讲解。

**要什么:** 完整推导、关键中间步骤、以及"为什么这样设计"的动机,而不是只给最终结论。会主动要求从电路图推导表达式(如 T-network、反馈网络)、讨论噪声预算、极点零点等。喜欢理解公式背后的来龙去脉。

**怎么学:** 论文/PPT 按章节或几页几页地学,保持连续进度,希望 AI 记住"上次学到第几页/哪个概念"。工具或平台的介绍也偏好结合具体使用场景和实例。

**如何应用:** 讲电路时给推导过程和中间步骤,不跳步;讲工具时给具体场景例子;精读材料时按小段推进并在每段后沉淀笔记。
