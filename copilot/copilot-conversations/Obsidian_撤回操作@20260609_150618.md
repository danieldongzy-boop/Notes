**ai**: 在 Obsidian 里“撤回操作”通常有几种：

- 撤销上一步编辑：  
  - Windows / Linux：`Ctrl + Z`
  - macOS：`Cmd + Z`

- 重做 / 取消撤销：  
  - Windows / Linux：`Ctrl + Shift + Z` 或 `Ctrl + Y`
  - macOS：`Cmd + Shift + Z`

- 通过命令面板执行：  
  - 按 `Ctrl + P` / `Cmd + P`
  - 搜索 `Undo` 或 `撤销`
  - 执行对应命令

如果你是想恢复误删的大段内容或误删笔记，可以用：

- 左下角设置
- `核心插件`
- 启用 `文件恢复`
- 打开 `文件恢复`
- 搜索对应笔记并恢复历史快照

如果只是普通输入错误，直接 `Ctrl + Z` / `Cmd + Z` 就可以。
