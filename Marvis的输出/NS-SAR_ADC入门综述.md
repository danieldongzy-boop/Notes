# Noise-Shaping SAR ADC 入门综述

> 核心文献来源：Lu Jie, Xiyuan Tang, Jiaxin Liu, Linxiao Shen, Shaolan Li, Nan Sun, Michael P. Flynn. **An Overview of Noise-Shaping SAR ADC: From Fundamentals to the Frontier.** IEEE Open Journal of the Solid-State Circuits Society, 2021.

---

## 一、什么是 Noise-Shaping SAR ADC？

### 1.1 背景

模数转换器（ADC）是现代电子系统中不可或缺的关键模块。随着移动设备和物联网的发展，对ADC的要求越来越高——既要高带宽（>100MHz）、高动态范围（>70dB），又要低功耗（仅几毫瓦）、低成本。

在这种背景下，**Noise-Shaping SAR（NS-SAR）** 是最近十年涌现的一种新型ADC架构。它将传统SAR ADC和ΔΣ调制器（DSM）的优点融合在一起。

| 架构 | 优点 | 缺点 |
|------|------|------|
| **SAR ADC** | 高能效、结构简单、适合工艺缩放 | 精度受限于比较器噪声和DAC匹配 |
| **ΔΣ调制器 (DSM)** | 高精度、噪声整形 | 需要高性能运放、功耗高 |
| **NS-SAR** | 兼具SAR的高能效和DSM的高精度 | 环路滤波器设计、DAC失配等新挑战 |

### 1.2 与传统SAR ADC的区别

你懂SAR ADC，那NS-SAR和它的核心区别在哪里？

传统SAR ADC逐次逼近完成一次转换后，残留电压（residue）被丢弃了。NS-SAR的关键思想是：**把这个残留电压保存下来，通过一个环路滤波器处理后，叠加到下一次转换中**。

这样一来，量化噪声的频率分布就被改变了——低频噪声被"推"到高频段（即噪声整形），带内精度大幅提升。

### 1.3 核心思想图解

```
传统SAR ADC:
  输入 -> [采样] -> [SAR逐次逼近] -> 输出 (残留丢弃)
  
NS-SAR ADC:
  输入 -> [采样] -> [SAR逐次逼近] -> 输出
                ↑                      ↓
                └── [环路滤波器] <── 残留电压
```

## 二、基本原理：噪声整形是怎么实现的？

### 2.1 两种基本结构

NS-SAR主要有两种实现结构：

#### EF结构（Error-Feedback，误差反馈）
- 残留电压直接经环路滤波器处理后反馈给下一次输入
- 优点：NTF设计灵活、系数可调
- 缺点：需要精确的模拟求和器

#### CIFF结构（Cascade of Integrators with Feed-Forward，前馈积分级联）
- 残留电压经无源或有源滤波器积分后前馈到比较器
- 优点：无需精确求和器，更简单
- 缺点：NTF灵活性较低

### 2.2 噪声传递函数（NTF）

NS-SAR可以实现的噪声整形阶数：
- 一阶整形：噪声功率降低约 9dB/倍频程
- 二阶整形：噪声功率降低约 15dB/倍频程
- 更高阶：每增加一阶，带内噪声进一步降低

## 三、核心技术挑战与解决方案

以下内容直接来自综述原文的核心章节（Section III）。

### 3.1 环路滤波器（Loop Filter）

环路滤波器是NS-SAR中唯一的"类模拟"模块，通常主导SNR和能效。但由于只处理微小残留电压，可以比传统ΔΣ的环路滤波器简单得多——甚至可以是完全无源的。

环路滤波器提供三个功能：
1. **滤波**：对残留电压进行LTI处理
2. **增益**：在特定频率放大残留电压
3. **求和**：将输出叠加回SAR

#### 无源策略

**方案一：多输入比较器**

在比较器输入端设置多个差分对，每个差分对尺寸不同。不同输入对的输出电流求和 → 同时实现信号放大和求和。

- 优点：简单、全动态、无静态功耗
- 缺点：噪声效率低，额外的输入对产生额外噪声；无源滤波器在前，kT/C噪声不被比较器增益抑制

**方案二：电容堆叠（Capacitor Stacking）**

源自电力电子中的倍压器思想：
1. 给两个电容分别充电
2. 将它们串联 → 电压相加（KVL原理）

- 优点：真正无源、线性度高、可提供整数增益
- 关键优势：输入参考kT/C噪声只与总电容有关，与堆叠数量无关。差分电容堆叠还能额外提供2倍增益并消除共模。
- 限制：输出驱动能力弱、对寄生电容敏感。目前NS-SAR中最高堆叠数为2（增益约4倍）。

#### 有源策略

有源环路滤波更灵活。早期使用简化的运放开关电容滤波器，后来引入：
- 动态gm-C放大器
- 开环gm-R放大器
- **闭环动态放大器**（Closed-loop Dynamic Amplifier）：兼顾性能和鲁棒性的最佳选择。闭环增益大、对时序不敏感、带宽在settling过程中自动收缩（改善噪声效率）

#### 级联噪声整形（Cascaded NS-SAR）

传统NS-SAR难以实现三阶以上NTF（电路变化导致性能退化严重）。

解决方案：将NS-SAR放在嵌套结构中。每一级接收上一级的已整形噪声，施加新一轮整形，再传递给下一级。这自然形成级联NTF，对变化容忍度高，且前者噪声被后者过滤。

这使4阶（2×2阶）NS-SAR成为可能。

### 3.2 DAC失配

DAC失配引入信号相关的误差 → 谐波失真 + 带内噪声增加。

#### 传统方案

- **增大DAC面积**：面积每增4倍，失配标准差减半。但与低成本目标矛盾。
- **数字后校准**：前台校准（简单，可到105dB SFDR但不能跟踪变化）/ 后台校准（实时但更复杂）

#### 数字失配整形（DEM / Dynamic Element Matching）

基于逐单元DAC操作，用单元选择逻辑（ESL）让失配误差与DAC码的相关性降低：
- 随机选择：打散误差
- DWA（Data Weighted Averaging）：一阶整形
- 高阶ESL：更高阶整形

**缺点**：需要逐单元操作，ESL逻辑复杂度随分辨率指数增长。通常只对高位MSB做DEM，低位LSB的误差不被抑制。目前NS-SAR中DEM最高实现112dB SFDR（但带宽仅2kHz）。

#### 模拟失配整形（MES / Mismatch Error Shaping）

基本思想：在采样前预置CDAC的LSB，使前次转换的失配误差在采样时被捕获，后续从数字输出中减去。

- 优点：实现简单、不需逐单元操作、性能与DEM相当（105dB SFDR）
- 挑战：预置LSB不仅反馈失配误差，也反馈前次输入信号 → 占用输入信号范围

解决方案：
- 只在部分LSB上做MES，MSB仍用DWA → 大幅减少输入范围损失
- 引入预测器补偿输入信号 → 恢复满量程

### 3.3 带宽限制与时间交织（Time-Interleaving）

过采样ADC的固有劣势：带宽受限。

时间交织是提升采样率的有效技术。但直接对NS-ADC做时间交织有两个问题：
1. 反馈延迟变为N倍，NTF形式被破坏
2. 通道间反馈不满足因果性（残留在下一个通道启动后才产生）

**解决方案：EF结构 TI-NS-SAR**

一个通道的残留直接馈给其他通道。任一时刻只有一个通道产生残留 → 只需一根共享导线承载所有通道间反馈。NTF设计灵活，系数可调。但模拟加法器实现难度大。

**CIFF结构 TI-NS-SAR**

各通道共享一个全局积分器。环路滤波器本身不被交织（运行在全速率），只交织SAR核心。

目前最快的低通TI-NS-SAR：80MHz带宽、66dB SNDR。

> 额外优势：当过采样率大于通道数时，TI-NS-ADC对通道间失配的敏感度降低——大多数失配误差落在带外。

### 3.4 输入驱动与kT/C噪声

高分辨率SAR ADC的经典问题：采样kT/C噪声。通常需要大采样电容 → 给信号源带来重负载。

NS-SAR中过采样降低了kT/C噪声功率（OSR倍），但采样频率增加使输入缓冲器的负担并未完全放松。

#### kT/C噪声降低技术

**技术一：反馈去耦**

用反馈电路解耦噪声源阻抗和噪声带宽。理论上可将kT/C噪声降低约 RF/(RL×2)。

**技术二：有源抵消**

用额外放大器和采样器捕获kT/C噪声，后续在数字域抵消。理想情况下可完全消除kT/C噪声，但引入额外放大器噪声。此技术已应用于NS-SAR：仅0.8pF采样电容实现87dB DR。
