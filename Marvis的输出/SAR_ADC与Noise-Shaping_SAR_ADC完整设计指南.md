## 一、前言：为什么选 SAR ADC

逐次逼近型模数转换器（SAR ADC）是中高精度（8-16 bit）、中速（100 kS/s - 100 MS/s）应用的首选架构。相比其他 ADC 架构：

| 架构 | 精度 | 速度 | 功耗 | 面积 | 典型应用 |
|------|------|------|------|------|----------|
| **SAR ADC** | 8-16 bit | 中等 | 极低 | 小 | 传感器、便携设备、IoT |
| Flash ADC | 4-8 bit | 极快 | 极高 | 大 | 高速示波器、雷达 |
| Pipeline ADC | 10-14 bit | 快 | 中等 | 中等 | 通信、视频 |
| Sigma-Delta ADC | 16-24 bit | 慢 | 中等 | 中等 | 音频、精密测量 |

**SAR ADC 的核心优势**：能效比极高，架构简单，与先进 CMOS 工艺天然兼容。

**Noise-Shaping SAR ADC** 是近年的研究热点，将 SAR ADC 与 Σ-Δ 调制器的噪声整形思想结合，在 SAR 基础上实现更高精度（>12 bit）而功耗增加有限。

本文将以 **中高精度 SAR ADC（10-16 bit）** 为目标，梳理从零开始的完整设计流程。

## 三、阶段一：指标确定与架构选择

### 3.1 核心指标定义

针对目标应用，首先明确以下参数：

| 参数 | 含义 | 典型设计目标 |
|------|------|-------------|
| 分辨率 (N) | 量化位数 | 10-16 bit |
| 采样率 (Fs) | 每秒采样次数 | 1 MS/s - 100 MS/s |
| ENOB（有效位数） | 实际精度 | 接近 N（如 16 bit → ENOB > 14） |
| SINAD / SNR | 信噪失真比 | SNR ≈ 6.02N + 1.76 dB |
| SFDR | 无杂散动态范围 | > 80 dB（高精度场景） |
| 功耗 | 总功耗预算 | < 1 mW（低功耗）或按需 |
| 输入范围 | 满量程电压 | Vref（如 1.0V、3.3V）|

### 3.2 架构选择决策树

```
SAR ADC 架构选择
├── 输入方式
│   ├── 单端：面积小、功耗低，适合 ≤10 bit
│   └── 全差分：共模抑制好、线性度高，适合 ≥10 bit
├── 时序方式
│   ├── 同步：设计简单，需高速主时钟
│   └── 异步：速度快、功耗低，适合 ≥50 MS/s
├── 采样方式
│   ├── 上极板采样：结构简单，Vcm-based 切换，适合 ≤10 bit
│   └── 下极板采样：线性度高，适合 ≥12 bit（但增加一次比较周期）
├── DAC 切换策略
│   ├── 传统切换：差分 2^N 个单位电容
│   ├── 单调切换 (Monotonic)：功耗低，共模电压漂移
│   ├── Vcm-based 切换：共模恒定，适合中高精度
│   └── 合并电容切换 (MCS)：进一步降低开关功耗
├── DAC 电容阵列
│   ├── 二进制权重：简单，但 MSB 匹配要求高
│   ├── 分段式 (Split)：面积小，适合 ≥10 bit
│   └── 非二进制冗余：允许 sub-radix-2，容忍建立误差
└── 是否扩展为 Noise-Shaping
    ├── 否 → 标准 SAR ADC
    └── 是 → 添加环路滤波器 + 余量采样（见第九章）
```

### 3.3 一个典型设计实例的架构选择

以 8 bit、200 MS/s、低功耗 SAR ADC 为例（28nm CMOS）：

- **输入方式**：单端（面积和功耗优先）
- **时序**：异步 SAR（避免高速时钟）
- **采样**：上极板采样 + CC.Liu VCM 单调拨动时序
- **CDAC**：总电容仅 128C（vs 差分下极板采样的 512C）
- **比较器**：双尾动态比较器（低回踢噪声，适合 1V 电源）
- **功耗**：< 300 μW

## 四、阶段二：MATLAB 行为级建模

### 4.1 建模目的

在实际电路设计前，必须用 MATLAB 建立完整的行为级模型，验证：

- 理想 ADC 的 SNR / ENOB 是否达标
- 电容失配对 DNL / INL 的影响
- 比较器噪声和失调的影响
- 开关非线性对 SFDR 的影响
- 建立时间不足带来的动态误差

### 4.2 建模关键步骤

#### Step 1：理想 SAR ADC 模型

```matlab
% 理想 N-bit SAR ADC 行为模型
N = 12;                    % 分辨率
Fs = 10e6;                 % 采样率
Vref = 1.0;                % 参考电压
fin = 0.499e6;             % 输入频率（相干采样）
Nfft = 4096;              % FFT 点数

% 生成输入信号
t = (0:Nfft-1) / Fs;
Vin = 0.5 * Vref * sin(2*pi*fin*t) + 0.5*Vref;

% 逐次逼近量化
Dout = zeros(1, Nfft);
for i_samp = 1:Nfft
    Vdac = 0.5 * Vref;     % 初始猜测 = Vref/2
    code = 0;
    for bit = N-1:-1:0
        if Vin(i_samp) >= Vdac
            code = code + 2^bit;
            Vdac = Vdac + Vref / 2^(N-bit);
        else
            Vdac = Vdac - Vref / 2^(N-bit);
        end
    end
    Dout(i_samp) = code;
end
```

#### Step 2：加入非理想效应

- **电容失配**：对每位电容加入高斯随机误差 `C_i = C_ideal_i * (1 + sigma_c * randn)`
- **KT/C 噪声**：采样阶段加入 `sqrt(k*T/Ctotal)` 的 RMS 噪声
- **比较器失调**：加入固定的 DC offset `Vos`
- **比较器噪声**：每次比较加入 `sigma_comp * randn`

#### Step 3：FFT 分析

对量化结果做 FFT，计算 SNR、SNDR、SFDR、ENOB：

```matlab
% FFT 分析
w = blackman(Nfft)';
spec = fft(Dout .* w) / Nfft;
spec_dB = 20*log10(abs(spec(1:Nfft/2)));

% 信号功率
sig_bin = round(fin/Fs * Nfft) + 1;
Psig = sum(abs(spec(sig_bin-2:sig_bin+2)).^2);
Pnoise = sum(abs(spec).^2) - Psig;

SNR = 10*log10(Psig / Pnoise);
ENOB = (SNR - 1.76) / 6.02;
```

#### Step 4：扫描关键参数

- 扫描单位电容值 → 确定失配和 KT/C 噪声的 trade-off
- 扫描比较器噪声 → 确定比较器设计指标
- 扫描采样开关 Ron → 确定开关尺寸

## 五、阶段三：采样开关设计

### 5.1 为什么需要栅压自举开关

普通 CMOS 开关的导通电阻随输入电压变化：

$$
R_{on} = \frac{1}{\mu_n C_{ox} \frac{W}{L} (V_{GS} - V_{TH})}
$$

当 $V_{in}$ 变化时 $V_{GS}$ 随之变化，导致 $R_{on}$ 非线性，产生谐波失真。

**栅压自举开关 (Bootstrapped Switch)** 使 $V_{GS}$ 恒定为 VDD，$R_{on}$ 恒定。

![Bootstrapped Switch](https://static.mianbaoban-assets.eet-china.com/xinyu-images/MBXY-CR-aea7729b7a14162ca9e67fb65000dc08.png)

> 图：栅压自举开关结构（来源：EET China / JSSC "An 8 Bit 4 GS/s 120 mW CMOS ADC"）

### 5.2 工作原理

1. **复位阶段**（S1 闭合，S2 断开）：自举电容 C 上极板接 VDD，下极板接 GND → C 充电至 VDD
2. **泵升阶段**（S1 断开，S2 闭合）：开关管源极接 C 下极板（即 $V_{in}$），栅极接 C 上极板 → $V_G = V_{in} + VDD$ → $V_{GS} = VDD$（恒定）

### 5.3 设计要点

| 设计参数 | 考虑因素 |
|----------|---------|
| 自举电容 C | 足够大以维持泵升电压，典型值 0.5-2 pF |
| 开关管尺寸 W/L | $R_{on}$ 需满足建立时间要求 |
| 寄生电容 | 栅-漏寄生电容 Cgd 带来时钟馈通，需在仿真中验证 |
| 可靠性 | 栅极泵升到 $V_{in}+VDD$ 可能超过栅氧击穿电压，先进工艺需注意 |
| 仿真要点 | **必须带负载电容仿真**，否则结果无意义 |

### 5.4 建立时间约束

$$
R_{on} \cdot C_{total} < \frac{0.5 \cdot T_s}{N \cdot \ln 2}
$$

其中 $T_s = 1/F_s$ 为采样周期，$N$ 为分辨率。

## 六、阶段四：电容 DAC (CDAC) 设计

### 6.1 CDAC 结构选择

#### 6.1.1 全二进制权重阵列

适用于 ≤ 10 bit。每位电容 $C_i = 2^{i} \cdot C_u$，MSB 电容 = $2^{N-1} \cdot C_u$。随分辨率增加，MSB 和 LSB 电容比值急剧增大，面积膨胀。

#### 6.1.2 分段式电容阵列（Split Capacitor Array）

适用于 ≥ 10 bit。通过桥接电容 $C_s$ 将阵列分为 MSB 段和 LSB 段，显著减小总电容：

- 例如 7-4-5 分段：高 7 位 + 桥接 + 低 5 位，总电容远小于全二进制
- 桥接电容 $C_s$ 的值需要精确计算，且对寄生敏感

#### 6.1.3 非二进制冗余设计 (Sub-radix-2)

权重基数 < 2（如 1.85），允许建立误差在后续周期被纠正。适合高速异步 SAR。

### 6.2 单位电容 $C_u$ 的确定——三大约束

这是整个 SAR ADC 设计中最关键的决策之一，需同时满足三个约束：

#### 约束 1：电容失配 → DNL/INL

对单位电容做 **蒙特卡洛仿真**，要求：

$$
\text{DNL}_{3\sigma} < \frac{1}{2} \text{LSB}, \quad \text{INL}_{3\sigma} < \frac{1}{2} \text{LSB}
$$

**蒙特卡洛仿真方法**：
- 对单位电容做 AC 仿真，频率设为 $f = 1/(2\pi) \approx 0.159$ Hz
- 此时 $I = j\omega C V = jC$（设 V=1）
- 用计算器打出电流虚部即为容值
- 跑 200+ 次 Monte Carlo，统计 $\sigma_C / C$

#### 约束 2：KT/C 热噪声

采样阶段的热噪声 RMS 值需小于量化噪声：

$$
\sqrt{\frac{kT}{C_{total}}} < \frac{V_{LSB}}{\sqrt{12}} = \frac{V_{ref}}{2^N \sqrt{12}}
$$

参考值：1 pF 电容在 300K 下的 KT/C 噪声约 64 μV RMS。

#### 约束 3：建立时间

CDAC 输出必须在半个比较周期内建立到 N 位精度：

$$
R_{on} \cdot C_{total} < \frac{0.5 \cdot T_{comp}}{N \cdot \ln 2}
$$

其中 $T_{comp}$ 为每位比较分配的时间。

### 6.3 三大约束的综合

**选取同时满足上述三个约束的最小 $C_u$**，以优化面积和功耗。典型流程：

1. 从失配约束得到 $C_{u,min,match}$
2. 从噪声约束得到 $C_{total,min,noise}$，换算 $C_{u,min,noise}$
3. 从建立时间约束验证 $C_u$ 是否过大（如过大则需降低 $R_{on}$）
4. 取 $\max(C_{u,min,match}, C_{u,min,noise})$ 并留 20% 裕量

### 6.4 DAC 开关切换策略

| 切换策略 | 总电容 (N bit) | 开关功耗 | 比较器共模 | 适用场景 |
|----------|---------------|----------|-----------|----------|
| 传统切换 | $2^N C_u$（差分） | 高 | 恒定 | 通用 |
| 单调切换 (Monotonic) | $2^{N-1} C_u$ | 低 | 漂移 | ≤ 10 bit，低功耗 |
| Vcm-based 切换 | $2^{N-1} C_u$ | 低 | 恒定 | ≥ 10 bit |
| 合并电容切换 (MCS) | 更少 | 最低 | 恒定 | 低功耗优先 |

### 6.5 电容驱动开关电路

每位电容需要一个驱动开关模块，根据 SAR 逻辑输出的 SW 信号将电容下极板接到 VREF 或 GND（Vcm-based 还有 VCM）。驱动电路需保证：

- 开关导通电阻足够低
- 驱动信号不重叠（non-overlapping）
- 对 VREF / GND / VCM 的驱动能力足够

## 七、阶段五：比较器设计

### 7.1 比较器类型选择

| 类型 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **静态比较器**（开环运放） | 增益高、噪声低 | 功耗极大 | 极少用于 SAR |
| **Strong-Arm 动态比较器** | 增益高、速度快、噪声低 | 回踢噪声大、需较高 VDD | ≥ 1.2V 电源 |
| **双尾动态比较器 (Double-Tail)** | 回踢噪声低、速度可调、适合低 VDD | 功耗略高 | ≤ 1.2V 电源，高精度 |

Strong-Arm 结构的输出仅经过一次 Cgd 耦合回输入端 → 回踢噪声高。

Double-Tail 结构输出经过两次 Cgd 才耦合回输入端 → 回踢噪声显著降低，且可通过两个尾电流管独立调节噪声和速度。

### 7.2 比较器关键指标

| 参数 | 要求 | 验证方法 |
|------|------|----------|
| 失调电压 | < 0.5 LSB | Monte Carlo 仿真 |
| 输入参考噪声 | < 0.5 LSB RMS | Transient noise 仿真 |
| 回踢噪声 (Kickback) | 不影响 DAC 建立 | Transient 仿真观察 DAC 输出 |
| 判决时间 | < 每位分配的比较时间 | 最差情况（输入 ≈ 阈值）仿真 |
| 亚稳态恢复 | 限幅时间内必然输出有效值 | 多 corner 仿真 |
| 功耗 | 每次比较的能量 | 平均电流 × VDD × 比较次数 |

### 7.3 比较器设计要点

- **预放大级**（可选）：降低输入参考噪声和失调，但增加功耗和延迟
- **输入对管尺寸**：大尺寸 → 低失调/低噪声，但增加寄生电容降低速度
- **正反馈锁存器**：交叉耦合对管的正反馈强度决定再生速度
- **复位开关**：每周期必须彻底复位，避免记忆效应

## 八、阶段六：SAR 逻辑电路设计

### 8.1 SAR 逻辑功能

SAR 逻辑是 ADC 的数字控制核心，负责：

1. 产生采样时钟（通常 10%-30% 占空比）
2. 在每个比较周期产生比较器时钟 CKC
3. 接收比较器输出，决定每位量化结果
4. 产生 CDAC 开关控制信号 SW 和 CLK
5. 在所有位完成后输出最终量化码

### 8.2 同步 vs 异步 SAR 逻辑

| 方式 | 时钟方案 | 优点 | 缺点 |
|------|----------|------|------|
| 同步 | 高速主时钟驱动所有周期 | 设计简单、时序确定 | 需要高频时钟、功耗高 |
| 异步 | 比较器完成信号触发下一周期 | 速度快、功耗低、无需高频时钟 | 时序需仔细设计 |

### 8.3 关键时序

```
|←──────────────── 一个采样周期 Ts ────────────────→|
|← 采样 (10-30% Ts) →|←── N 次比较和 DAC 建立 ──→|
                       |← CKC →|← DAC settle →|← CKC →|...
```

- 采样阶段占空比：10%-30% 典型（经验值，取决于建立时间需求）
- 每次比较后 DAC 需要一定的建立时间
- 异步 SAR 中，比较器完成信号（Ready）触发下一位的 CKC

### 8.4 可配置分辨率设计

通过 BIT_SEL 信号控制转换位数（如 2-8 bit 可配置），灵活适应不同精度-速度-功耗需求。

## 九、阶段七：Noise-Shaping SAR ADC 扩展

### 9.1 为什么需要 Noise-Shaping SAR

传统 SAR ADC 的精度受限于：
- 比较器噪声
- KT/C 噪声
- DAC 电容失配

对于 >12 bit 精度，单纯增大电容和功耗开销极大。**Noise-Shaping SAR ADC** 将转换后的**余量电压**（Residue）通过环路滤波器积分，在下一次转换中抵消低频量化噪声，实现噪声整形。

### 9.2 NS-SAR 架构选择

| 架构 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **误差反馈式 (EF)** | 将上一次量化误差反馈到下一次输入 | 结构简单、NTF 易设计 | 需要精确的误差提取 |
| **级联积分前馈式 (CIFF)** | 积分器处理环路滤波，前馈求和 | NTF 灵活、稳定性好 | 需要求和电路 |
| **无源环路滤波器** | 开关电容实现无源积分 | 无静态功耗 | 增益衰减、精度受限 |
| **有源环路滤波器** | 运放实现有源积分 | 增益高、噪声低 | 功耗增加 |
| **电容叠加+缓冲 (Cap Stacking + Buffering)** | 电容堆叠实现积分+缓冲隔离 | 能效极高、适合高阶 | 设计复杂 |

### 9.3 NS-SAR 设计流程

#### Step 1：确定目标 NTF

根据过采样率 OSR 和精度需求设计噪声传递函数 NTF：

$$
NTF(z) = (1 - z^{-1})^L
$$

其中 $L$ 为噪声整形阶数。一阶 $L=1$ 对 ENOB 提升约 $0.5 \log_2(OSR) + \text{常数}$ 位。

#### Step 2：选择环路滤波器类型

- **一阶无源**：最简，用开关电容积分，但信号衰减需补偿
- **一阶有源**：运放积分器，增益补偿准确，功耗适中
- **二阶及以上**：需谨慎设计稳定性，通常需要前馈/反馈组合

#### Step 3：余量电压采样

SAR 转换完成后，DAC 上的残差电压即为量化误差。需设计余量采样电路提取此电压送入环路滤波器。

#### Step 4：求和方式

- **电容叠加**：在比较器输入端用电容耦合叠加输入信号和滤波后的余量
- **多输入比较器**：比较器自身实现加权求和（如 6 输入比较器）
- **电荷重分配**：在 CDAC 采样阶段直接注入余量电荷

#### Step 5：时序设计

标准 SAR 的 N 个比较周期 + 额外的余量采样和积分周期。需合理安排时序，确保在采样率内完成。

### 9.4 NS-SAR 噪声分析

总输入参考噪声应满足：

$$
v_{n,total}^2 = v_{n,KT/C}^2 + v_{n,comp}^2 + v_{n,ref}^2 + v_{n,quant}^2 \cdot |NTF|^2
$$

其中 $v_{n,quant}^2 \cdot |NTF|^2$ 表示量化噪声经整形后在带内的残留。

### 9.5 一个实际 NS-SAR 设计案例

来自万方学位论文 "高精度低功耗 Noise-shaping SAR ADC 设计"：

- **工艺**：CMOS 180nm
- **架构**：级联积分前馈式 (CIFF)，二阶噪声整形
- **CDAC**：分段式非二进制电容阵列，带冗余
- **环路滤波器**：有源无损积分器
- **比较器**：6 输入动态比较器（同时完成求和与比较）
- **余量提取**：电容叠加求和
- **SAR 逻辑**：含 IMCS 算法电路

完整章节结构（来自该论文）：
1. 采样开关 → 栅压自举开关设计
2. CDAC → 分段式非二进制电容阵列 + 建立时间/冗余量分析
3. 比较器 → Strong-Arm + 6 输入比较器
4. SAR 逻辑 → IMCS 算法实现
5. 环路滤波器 → 有源/无源无损积分器
6. 余量求和 → 电容叠加 / 多输入比较器
7. NTF 分析和噪声预算分配
8. 整体电路仿真验证

### 10.2 后仿真流程

1. **Calibre PEX**：提取寄生参数（R+C+CC）
2. **后仿真**：将寄生网表代入，重跑关键仿真
3. **对比前仿**：评估寄生导致的性能退化
4. **迭代优化**：根据后仿结果微调关键器件

### 10.3 关键后仿检查项

- ENOB 退化是否 < 0.5 bit
- SFDR 是否仍达标
- 时序是否闭合（建立时间、保持时间）
- 功耗是否在预算内
- 各 corner 下功能是否正确
